# Microservicio Equipos
Este microservicio consiste en la creación de un equipo el cual sera asignado a un torneo. Tambien se le podra hacer cambios a dicho equipo siempre y cuando el rol de quien lo haga
sea Admin o Arbitro si es Jugador o Coach no se le permitira. Tambien esta conectado con Auditoria para registrar cambios como la creacion de un equipo, el update o la eliminación.

## Dependencias
* Spring Web
* Validation
* Spring Data JPA
* OpenFeign
* MySQL Driver
* Lombok
